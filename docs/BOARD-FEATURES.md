# Board features

English | [简体中文](BOARD-FEATURES.zh-CN.md)

What each board's firmware build contains, generated by `scripts/gen-docs`
from the `features.json` the build writes
([features-json](dev/features-json.md)); CI fails when this page drifts from
the code. It says what is built, not what has run: board results are on the
board pages ([ROCK 4D](boards/rock4d.md), [CM5-IO](boards/cm5io.md),
[TaishanPi 3M](boards/tspi3m.md)).

"yes, X" gives the default; a setup option's row gives its default, or
"hidden" when the board's build does not offer it.
