# Setup settings reference

English | [简体中文](settings.zh-CN.md)

Every setup option that is stored in a UEFI variable, with its menu, its
variable and its default on each board. The tables are generated by
`scripts/gen-docs` from the `features.json` each build writes
([features-json](dev/features-json.md)); CI fails when they drift. What the
options do: [firmware menus](firmware-menus.md).

"hidden" means the board's build hides the option (`Pcd<X>Supported` is
FALSE). "@n" is the byte offset of the option inside a variable that holds
several.
