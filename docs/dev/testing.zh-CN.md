# 测试

[English](testing.md) | 简体中文

对这个固件来说"测试过"是什么意思，以及在哪里跑过什么。

## CI 检查什么

`.github/workflows/build.yml` 在每次 push 到 `main` 和每个 pull request 上构建所有板子。它检查映像能否构建成功，以及每个 SD 和 eMMC 映像里的变量存储是否在 `package.sh` 预期的位置。它不在硬件上运行任何东西。`main` 构建成功后会替换 `ci` 预发布版。

## 在板子上

每种板子只有一块。结果写在合并提交里（"Board-verified on the TaishanPi 3M on <date>: ..."）和正式版说明里（"How it was tested"）。

经常把几个分支合在一个测试映像里（命名为 `test-all-<date>` 之类），一起在泰山派 3M 上跑；合并信息里会写明是哪个映像。
